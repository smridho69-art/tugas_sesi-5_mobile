# TicTacToe – Pemrograman Mobile Sesi 5

##  Deskripsi
TicTacToe merupakan aplikasi permainan sederhana berbasis mobile yang dikembangkan menggunakan React Native dengan framework Expo.

Aplikasi ini mengimplementasikan permainan TicTacToe atau X dan O yang dimainkan oleh dua pemain secara bergantian pada papan permainan berukuran 3 × 3.

Project ini dibuat untuk memenuhi tugas mata kuliah Pemrograman Mobile Sesi 5.

##  Fitur Aplikasi
- **Papan Permainan:** Menampilkan kotak permainan berukuran 3 × 3.
- **Dua Pemain:** Permainan dapat dimainkan oleh dua pemain, yaitu X dan O.
- **Pergantian Giliran:** Pemain bergantian memilih kotak yang tersedia.
- **Deteksi Pemenang:** Menentukan pemain yang berhasil membentuk tiga simbol secara berurutan.
- **Hasil Seri:** Mendeteksi kondisi ketika seluruh kotak terisi tanpa adanya pemenang.
- **Reset Permainan:** Memulai kembali permainan dari awal.

## Cara Menjalankan Project

### 1. Clone Repository

```bash
git clone https://github.com/MochammadNazib/PemrogramanMobile_sesi5.git
```

### 2. Masuk ke Folder Project

```bash
cd PemrogramanMobile_sesi5
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Jalankan Project

```bash
npx expo start
```

### 5. Menjalankan pada Android

Untuk menjalankan aplikasi menggunakan emulator Android:

```bash
npm run android
```

Pastikan emulator Android sudah aktif sebelum menjalankan aplikasi.
